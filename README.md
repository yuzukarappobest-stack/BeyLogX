# ベイログX

ベイブレードXの対戦構成と結果を記録するSwiftUI製iPhoneアプリです。

## 現在できること

- 自分・相手のBX / UX、CX、CXエクスパンド構成を選択
- 未選択のパーツを含む対戦記録
- スタジアム（エクストリーム／インフィニティ）の選択
- 勝敗、決まり手、日時、メモの記録
- JSONによる端末内の自動保存
- 全パーツを別列にしたUTF-8 CSVの書き出し
- 履歴の閲覧と削除
- ブレード構成と任意のビットで結果検索
- 対戦相手のブレード構成＋ビット別に、勝敗数・勝率・獲得／失点ポイントを集計
- 自分・相手の登録位置を区別せず、選択したベイ基準で決まり手別の勝ち方・負け方回数を表示
- 試合中に自分・相手それぞれでリバースが発生したかを結果として記録
- 結果検索でリバース発生回数・発生率を表示
- 結果検索ではCXロックチップをエンペラー／ワルキューレ／プラチップの性能区分で集計
- iPhone版とWeb版で共通のJSONバックアップを読み書き可能

## 動作環境

- Xcode 16以降
- iOS 17以降

`BeyLogX.xcodeproj` をXcodeで開き、開発チームとBundle Identifierを必要に応じて設定して実行してください。

パーツ候補は「競技玩具研究所 ベイブレードX パーツ一覧」（2026-07-18更新）を参照しています。

## Web版

`docs/` はGitHub Pagesで公開できる、依存ライブラリなしの静的PWAです。

- 対戦入力、履歴、削除、勝敗分析
- 自分と対戦相手の構成・勝敗・試合後イベントをまとめて入れ替え
- 自分・相手のリバースと自滅の記録、ブレード＋ビット単位の自滅回数・自滅率の分析
- 10戦以上の組み合わせを対象にした有利・不利・互角・傾向混在の判定と、勝率・ポイント期待値の昇順／降順ランキング
- 自分側・相手側を区別しないベイ基準の分析
- IndexedDBへの自動保存と永続ストレージ要求
- オフライン利用用Service Worker
- 更新時はネットワークを優先し、古いキャッシュが残った端末向けの `update.html` を用意
- JSONの書き出し・読み込み、CSV出力
- JSON読み込み時は既存データを保持し、IDが新しい記録だけ追加

ローカル確認:

```sh
python3 -m http.server 4173 --directory docs
```

その後 `http://localhost:4173/` を開きます。

## iPhone版とWeb版のデータ移行

JSONが相互移行用の正式なバックアップ形式です。

1. 移行元の「データ」または対戦履歴メニューからJSONを書き出す
2. 移行先で「JSONバックアップを読み込む」を選ぶ
3. 同じ記録IDは重複せず、新しい記録だけが追加される

CSVは表計算・閲覧用です。アプリへ戻す場合はJSONを使用します。

Web版はブラウザのIndexedDBへ自動保存しますが、ブラウザのサイトデータ削除や公開URL変更の影響は受けます。定期的なJSONバックアップを推奨します。

## GitHub Pages

GitHubリポジトリの Settings → Pages → Build and deployment で、Sourceを「Deploy from a branch」、Branchを `main` / `/docs` に設定すると公開されます。
